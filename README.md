# Portfólio Pessoal - Fernando Rodrigues Pinto

Este é o meu portfólio pessoal, desenvolvido como entrega oficial para a disciplina, focado em evidenciar de forma prática minhas habilidades em desenvolvimento frontend, meus principais projetos e minha trajetória acadêmica e profissional.

O projeto adota o estilo visual **Midimalista** (70% base limpa e funcional, 30% texturas e cores pontuais afetivas), focado em performance, semântica e clareza de navegação.

## Tecnologias Utilizadas
O projeto cumpre rigorosamente as **restrições técnicas** da avaliação (sem uso de frameworks JavaScript como React, Vue ou bibliotecas CSS como Tailwind), empregando exclusivamente:
- **HTML5:** Semântico, otimizado e acessível.
- **CSS3:** Estilizações customizadas para hover cards, tipografia e responsividade.
- **JavaScript (Vanilla):** Funcionalidades pontuais de interface e DOM sem dependências externas pesadas.
- **Bootstrap 5:** Grid System e utilitários base para garantir adaptabilidade aos dispositivos móveis.

## Instruções de Execução
O portfólio é um projeto estático e totalmente independente (não necessita de bancos de dados locais ou ambientes virtuais Node/Python).
Para executá-lo em sua máquina:
1. Clone ou faça o download deste repositório para o seu computador.
2. Navegue até a pasta raiz do projeto (`portfolio`).
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente em seu navegador web (Google Chrome, Firefox, Safari ou Edge).

*(Dica: Caso utilize o VS Code, você pode usar a extensão **Live Server** para rodar o projeto em um servidor local).*

## Resumo das Funcionalidades Implementadas (MVP)
Este projeto reflete perfeitamente a rastreabilidade do Backlog (Must have) mapeado na documentação:
- **Apresentação Pessoal:** Nome, contato rápido (E-mail e LinkedIn) e resumo do foco profissional (Hero Section).
- **Hard Skills:** Grade visual exibindo a proficiência em linguagens e metodologias por meio de um sistema de avaliação de estrelas (1 a 3).
- **Grid de Projetos e Trade-offs:** Cartões de projetos responsivos que exibem "badges" com tecnologias utilizadas, status (Público/Privado) e cartões flutuantes assíncronos focados em explicações dos **Desafios Técnicos** e no **Impacto de Negócio**.
- **Experiências Relevantes:** Linha do tempo (timeline) detalhando meu cargo, atuação de mercado e foco em arquitetura web.
- **Formação Acadêmica:** Histórico escolar em ordem cronológica reversa focada nas especializações do IFSP.
- **Hobbies (Além do Código):** Mapeamento minimalista e sem imagens extras sobre interesses pessoais relevantes para o desenvolvimento do pensamento crítico.
