Interface do Buskasher
Buskasher

Sistema de busca de produtos kosher e validação de certificação em mercados locais.

Problema & Solução: O maior desafio técnico foi arquitetar uma busca eficiente que mantivesse baixo tempo de resposta em um banco relacional com alto volume de itens.

Decisões Técnicas: Optou-se por PHP puro e queries otimizadas com índices no MySQL para maximizar a performance na produção, priorizando velocidade de resposta em vez da agilidade de um framework MVC pesado. O frontend utiliza Bootstrap e Vanilla JS, garantindo resposta ágil e ampla retrocompatibilidade.

Problema de Negócio: Consumidores tinham dificuldade em encontrar e verificar quais produtos nos mercados locais possuíam certificação kosher confiável.

Valor Gerado: Plataforma centralizada que permite achar produtos confiáveis instantaneamente, melhorando a experiência de compra do consumidor final e impulsionando as vendas de comércios locais certificados.

PHP MySQL Bootstrap HTML CSS JavaScript

Interface do Desafio Técnico
Desafio Técnico - Controle de Gastos

Painel financeiro para gestão e controle de despesas em tempo real.

Problema & Solução: A aplicação precisava lidar com fluxos de entrada/saída financeira e reatividade de estado complexo, mitigando re-renderizações desnecessárias e garantindo tipagem forte de ponta a ponta.

Decisões Técnicas: Ecossistema React + TypeScript para criar componentes desacoplados e previsíveis. O back-end em .NET (C#) provê uma API RESTful fundamentada em princípios SOLID, com alta segurança transacional e arquitetura em camadas.

Problema de Negócio: Pessoas físicas frequentemente se perdem em planilhas manuais e formulários desconexos, dificultando o controle financeiro pessoal.

Valor Gerado: Painel analítico limpo onde o usuário categoriza suas receitas e despesas em segundos, devolvendo o controle financeiro com clareza imediata e sem fricção.

React TypeScript HTML CSS Tailwind .NET C#
