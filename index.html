Buskasher

Sistema de busca de produtos kosher.

Ver Desafios Técnicos e Soluções
Problema & Solução: O maior desafio técnico foi arquitetar uma busca eficiente que mantivesse baixo tempo de resposta em um banco relacional com alto volume de itens.

Decisões Técnicas: Optou-se por PHP puro e queries otimizadas com índices no MySQL para maximizar a performance na produção, preferindo a velocidade de resposta em vez da agilidade de um framework MVC pesado. O front end utiliza jQuery e Bootstrap garantindo rápida prototipagem e retrocompatibilidade.
Impacto no Negócio
Problema de Negócio: Consumidores tinham dificuldade em encontrar e verificar quais produtos nos mercados locais possuíam certificação kosher.

Valor Gerado: Criamos uma plataforma centralizada que permite achar produtos confiáveis instantaneamente, melhorando a experiência de compra do consumidor final e impulsionando as vendas de mercados locais certificados.

Desafio Técnico - Controle de Gastos

Desafio técnico de controle de gastos.

Ver Desafios Técnicos e Soluções
Problema & Solução: A aplicação precisava lidar com estados complexos de UI (dados de entrada/saída financeira) de maneira reativa, evitando renderizações desnecessárias e sem abrir mão da tipagem forte.

Decisões Técnicas: Escolheu-se o ecossistema React + TypeScript para criar componentes estáveis e autônomos. Tailwind substituiu o CSS puro pela escalabilidade de design tokens. O back-end foi implementado em .NET (C#) criando uma API rigorosa focada em SOLID e bons design patterns.
Impacto no Negócio
Problema de Negócio: Pessoas físicas frequentemente se perdem em planilhas financeiras manuais complexas, dificultando o controle de seus próprios gastos.

Valor Gerado: Desenvolvemos um painel amigável e limpo onde o usuário consegue visualizar e categorizar suas despesas em segundos, devolvendo o controle financeiro para suas mãos de forma simples.
React TypeScript HTML CSS Tailwind .NET C#
